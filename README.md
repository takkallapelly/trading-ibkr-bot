# Trading IBKR Bot

## Installation

To clone the repository, run:

```bash
git clone https://github.com/takkallapelly/trading-ibkr-bot.git
cd trading-ibkr-bot
```

## Features

1. Comprehensive trading algorithms.

2. Customizable trading strategies.

3. Real-time data tracking and visualization.

4. Support for multiple brokerage accounts.


## Code Structure

The project structure is as follows:

- `src/data/                # Phase 2: DataLoader, IntradayFetcher, features, VIX, store`
- `src/execution/           # Phase 7: LiveTrader, IBKRClient, OrderManager, safety, scheduler`
